# CloudNine Systems

A proposed logical entity-relationship model for the CloudNine Systems group project: a cloud provider managing resources, reservations, deployments, usage, services, and billing.

## ERD documentation

- [Complete ERD and business rules](docs/CloudNine_Complete_ERD.md): 42 entities, 90 relationships, keys, requirements coverage, and modeling assumptions.
- [Four module diagrams](docs/CloudNine_ERD_Modules.md): clients and access; infrastructure; reservations and deployments; pricing and billing.
- [Mermaid source](docs/CloudNine_Complete_ERD.mmd): editable source for the complete diagram.

The Markdown diagrams render with GitHub's Mermaid support. The module views are recommended for reading and presentations; the full diagram provides an overall reference.

## Source and scope

The model is based on [the CloudNine Systems project brief](Group%20Project_%20CloudNine%20Systems.pdf). It is a proposed design, not an implemented database. Assumptions and constraints that cannot be expressed graphically are documented alongside the complete ERD.
